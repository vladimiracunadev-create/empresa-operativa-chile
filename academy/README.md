# Academia / Sandbox

El aprendizaje es una capacidad del producto, no su objetivo principal.

- `curriculum/`: ruta formativa desde fundamentos hasta cierre anual.
- `labs/`: ejercicios unitarios con solución.
- `cases/`: casos integrales.
- `data/scenarios/`: escenarios precargados.
- Modo `sandbox`: aplicación operativa con base de datos separada.

## Regla de seguridad

Nunca se copia automáticamente una operación del sandbox hacia Empresa Real. Si una práctica se desea convertir en operación real, debe registrarse nuevamente y acompañarse de su evidencia real.
