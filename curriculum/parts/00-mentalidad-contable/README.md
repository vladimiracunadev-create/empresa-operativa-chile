# Parte 00 — Mentalidad contable

## Pregunta que guía la parte

Aprender a reconstruir hechos con documentos y no a memorizar nombres de cuentas.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C01 — Qué resuelve la contabilidad](classes/C01.md) — Explicar qué preguntas responde un sistema contable.
2. [C02 — Documentos, hechos y evidencia](classes/C02.md) — Separar hecho, documento, registro y evidencia.
3. [C03 — Devengado vs percibido/pagado](classes/C03.md) — Distinguir reconocimiento económico y movimiento de caja.
4. [C04 — Ciclo mensual y anual](classes/C04.md) — Ubicar cada control en su frecuencia correcta.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
