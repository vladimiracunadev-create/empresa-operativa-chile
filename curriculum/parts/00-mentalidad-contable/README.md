# Parte 00 — Mentalidad contable

## Objetivo

Dominar mentalidad contable mediante explicación, simulación, registro y verificación.

## Clases

1. **Qué resuelve la contabilidad**
2. **Documentos, hechos y evidencia**
3. **Devengado vs percibido/pagado**
4. **Ciclo mensual y anual**

## Criterio de aprobación

El estudiante debe poder explicar la operación, calcularla, registrar su efecto y señalar qué evidencia/fuente oficial usaría para verificarla.
