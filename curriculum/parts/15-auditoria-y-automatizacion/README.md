# Parte 15 — Auditoría y automatización

## Objetivo

Dominar auditoría y automatización mediante explicación, simulación, registro y verificación.

## Clases

1. **Muestreo y pruebas**
2. **Alertas de inconsistencias**
3. **Reglas versionadas**
4. **Diseño de un contador virtual seguro**

## Criterio de aprobación

El estudiante debe poder explicar la operación, calcularla, registrar su efecto y señalar qué evidencia/fuente oficial usaría para verificarla.
