# Parte 12 — Municipal y cumplimiento

## Pregunta que guía la parte

Controlar patente y obligaciones con vigencia, fuente y ámbito.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C49 — Patente municipal](classes/C49.md) — Calcular sólo con base, tasa, comuna y período verificados.
2. [C50 — UTM y actualizaciones](classes/C50.md) — Usar el valor del período correcto.
3. [C51 — Contratos y oficina virtual](classes/C51.md) — Controlar vigencia, servicio y dependencia laboral.
4. [C52 — Matriz de obligaciones](classes/C52.md) — Mantener frecuencia, próxima fecha, fuente y evidencia.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
