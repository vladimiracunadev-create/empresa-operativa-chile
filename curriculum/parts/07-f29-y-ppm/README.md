# Parte 07 — F29 y PPM

## Pregunta que guía la parte

Preparar un control mensual explicable sin confundirlo con presentación.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C29 — Anatomía F29](classes/C29.md) — Reconocer componentes y procedencia de datos.
2. [C30 — IVA débito y crédito](classes/C30.md) — Conciliar impuesto de ventas, compras y remanente.
3. [C31 — PPM Pro Pyme](classes/C31.md) — Calcular anticipo sólo con régimen, base y tasa vigentes.
4. [C32 — Plazos, pago y rectificación](classes/C32.md) — Separar vencimiento, presentación, pago y corrección.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
