# Parte 08 — Honorarios

## Pregunta que guía la parte

Controlar bruto, líquido, retención y evidencia sin duplicar costos.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C33 — Boleta recibida](classes/C33.md) — Validar emisor, servicio, fecha y monto bruto.
2. [C34 — Retención 15,25% 2026](classes/C34.md) — Aplicar la tasa 2026 sin convertirla en regla eterna.
3. [C35 — Pago y F29](classes/C35.md) — Conectar pago líquido con retención por enterar.
4. [C36 — Casos con o sin retención](classes/C36.md) — Evitar inferir obligación desde una etiqueta incompleta.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
