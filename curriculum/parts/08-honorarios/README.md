# Parte 08 — Honorarios

## Objetivo

Dominar honorarios mediante explicación, simulación, registro y verificación.

## Clases

1. **Boleta recibida**
2. **Retención 15,25% 2026**
3. **Pago y F29**
4. **Casos con/sin retención**

## Criterio de aprobación

El estudiante debe poder explicar la operación, calcularla, registrar su efecto y señalar qué evidencia/fuente oficial usaría para verificarla.
