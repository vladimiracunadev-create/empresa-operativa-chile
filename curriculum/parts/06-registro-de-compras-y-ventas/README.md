# Parte 06 — Registro de Compras y Ventas

## Pregunta que guía la parte

Conciliar documentos propios con el registro oficial sin copiar a ciegas.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C25 — RCV ventas](classes/C25.md) — Comparar DTE emitidos, anulados y ajustados con el registro.
2. [C26 — RCV compras](classes/C26.md) — Revisar documentos recibidos y su clasificación.
3. [C27 — Caracterización](classes/C27.md) — Asignar tratamiento sin perder el documento original.
4. [C28 — Conciliación RCV ↔ documentos](classes/C28.md) — Cerrar diferencias entre fuente oficial y expediente interno.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
