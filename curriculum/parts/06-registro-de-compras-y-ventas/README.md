# Parte 06 — Registro de Compras y Ventas

## Objetivo

Dominar registro de compras y ventas mediante explicación, simulación, registro y verificación.

## Clases

1. **RCV ventas**
2. **RCV compras**
3. **Caracterización**
4. **Conciliación RCV ↔ documentos**

## Criterio de aprobación

El estudiante debe poder explicar la operación, calcularla, registrar su efecto y señalar qué evidencia/fuente oficial usaría para verificarla.
