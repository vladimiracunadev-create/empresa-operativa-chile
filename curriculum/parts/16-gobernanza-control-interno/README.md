# Parte 16 — Gobernanza, control interno y auditoría continua

## Pregunta que guía la parte

Diseñar decisiones, controles e investigaciones con responsabilidad y evidencia.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C65 — Gobierno corporativo, integridad y RACI](classes/C65.md) — Asignar responsable, aprobador, consultado e informado.
2. [C66 — Segregación de funciones](classes/C66.md) — Separar etapas incompatibles o crear compensaciones.
3. [C67 — Diseño y clasificación de controles](classes/C67.md) — Definir objetivo, tipo, frecuencia y evidencia.
4. [C68 — Libros auxiliares, conciliación, documentos y custodia](classes/C68.md) — Conectar detalle, mayor y evidencia preservada.
5. [C69 — Risk register, KRI, excepciones y auditoría continua](classes/C69.md) — Medir riesgo residual y excepciones vencidas.
6. [C70 — Whistleblowing, investigación independiente y remediación](classes/C70.md) — Preservar denuncias y separar hechos de hipótesis.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
