# Parte 11 — Activos y cierre contable

## Objetivo

Dominar activos y cierre contable mediante explicación, simulación, registro y verificación.

## Clases

1. **Activo vs gasto**
2. **Depreciación conceptual**
3. **Provisiones y ajustes**
4. **Cierre de resultados**

## Criterio de aprobación

El estudiante debe poder explicar la operación, calcularla, registrar su efecto y señalar qué evidencia/fuente oficial usaría para verificarla.
