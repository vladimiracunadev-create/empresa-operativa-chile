# Parte 11 — Activos y cierre contable

## Pregunta que guía la parte

Reconocer recursos de largo plazo y ajustes sin inventar valores.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C45 — Activo vs gasto](classes/C45.md) — Decidir si un desembolso beneficia uno o varios períodos.
2. [C46 — Depreciación conceptual](classes/C46.md) — Entender distribución del costo sin usar tasas inventadas.
3. [C47 — Provisiones y ajustes](classes/C47.md) — Registrar estimaciones como estimaciones revisables.
4. [C48 — Cierre de resultados](classes/C48.md) — Cerrar ingresos y gastos preservando el detalle del período.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
