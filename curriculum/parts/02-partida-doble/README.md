# Parte 02 — Partida doble

## Pregunta que guía la parte

Construir asientos desde cambios económicos y comprobar su equilibrio.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C09 — Activo, pasivo y patrimonio](classes/C09.md) — Clasificar recursos, obligaciones y parte residual.
2. [C10 — Debe y haber](classes/C10.md) — Usar Debe/Haber después de identificar la cuenta y su cambio.
3. [C11 — Ingresos y gastos](classes/C11.md) — Separar resultado de caja, capital y deuda.
4. [C12 — Balance de comprobación](classes/C12.md) — Usar el balance para detectar, no para ocultar, errores.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
