# Parte 02 — Partida doble

## Objetivo

Dominar partida doble mediante explicación, simulación, registro y verificación.

## Clases

1. **Activo/pasivo/patrimonio**
2. **Debe y haber**
3. **Ingresos y gastos**
4. **Balance de comprobación**

## Criterio de aprobación

El estudiante debe poder explicar la operación, calcularla, registrar su efecto y señalar qué evidencia/fuente oficial usaría para verificarla.
