# Parte 13 — Cierre mensual

## Objetivo

Dominar cierre mensual mediante explicación, simulación, registro y verificación.

## Clases

1. **Checklist**
2. **Conciliaciones cruzadas**
3. **Control de errores**
4. **Carpeta de evidencia**

## Criterio de aprobación

El estudiante debe poder explicar la operación, calcularla, registrar su efecto y señalar qué evidencia/fuente oficial usaría para verificarla.
