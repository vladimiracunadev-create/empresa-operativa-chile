# Parte 13 — Cierre mensual

## Pregunta que guía la parte

Cerrar períodos con controles, evidencia y recuperación explícita.

Esta parte usa el caso continuo de Ruta Andina SpA. Cada clase produce una evidencia distinta; leer sin resolver el taller no cuenta como finalización.

## Recorrido

1. [C53 — Checklist](classes/C53.md) — Definir pasos mínimos antes de congelar un mes.
2. [C54 — Conciliaciones cruzadas](classes/C54.md) — Comparar fuentes independientes y explicar diferencias.
3. [C55 — Control de errores](classes/C55.md) — Clasificar error, impacto y corrección sin borrar historia.
4. [C56 — Carpeta de evidencia](classes/C56.md) — Organizar un expediente que otra persona pueda revisar.

## Criterio de dominio

La parte queda dominada cuando las evidencias de todas sus clases cumplen sus criterios de aceptación y la persona puede explicar cómo una decisión cambia el registro, la caja, la obligación y la evidencia.
