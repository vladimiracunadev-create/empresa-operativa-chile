# Ciclo de vida controlado por la aplicación

`IDEA → PREPARACIÓN → CONSTITUIDA → INICIO SII → HABILITADA PARA OPERAR → OPERACIÓN MENSUAL → CIERRE ANUAL → CRECIMIENTO / CAMBIOS → TÉRMINO DE GIRO`

Cada transición exige un checklist y, cuando corresponde, evidencia oficial.

## Expediente mínimo de constitución
- borrador societario;
- certificado/estatuto vigente;
- RUT;
- domicilio y contrato de oficina virtual;
- inicio de actividades;
- actividades económicas;
- régimen tributario;
- habilitación DTE;
- patente municipal;
- cuenta bancaria;
- políticas contables iniciales.
