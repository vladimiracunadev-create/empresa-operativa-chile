# Empresa Real vs Sandbox

| Capacidad | Empresa Real | Sandbox |
|---|---:|---:|
| Datos persistentes | Sí | Sí, base separada |
| Efecto en cierres | Sí | Sólo práctica |
| Bitácora | Obligatoria | Sí |
| Evidencia oficial | Requerida para marcar cumplimiento | Ficticia |
| Reset | No destructivo por defecto | Permitido |
| Trámites SII/RES | Seguimiento de trámite real | Simulación |
| Reglas tributarias | Versión validada | La misma versión, con avisos pedagógicos |

Nunca debe existir una función `copiar todo a real`.
