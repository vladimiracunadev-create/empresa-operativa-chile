# Bibliografía secundaria y lecturas de profundización

**Fecha de consulta: 22 de septiembre de 2026.** Este archivo reúne fuentes secundarias, testimoniales y técnicas. Las normas y documentos oficiales están en [SOURCES-2026.md](SOURCES-2026.md).

## Criterio de uso

Una lectura secundaria ayuda a formular preguntas, reconocer patrones y comparar marcos. No reemplaza una ley, sentencia, resolución o expediente. Si una obra relata conversaciones, presiones o motivaciones que no cuentan con corroboración primaria independiente, el repositorio las presenta como afirmaciones o tesis del autor.
