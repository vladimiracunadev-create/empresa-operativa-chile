# Árbol de decisión: ¿lo hago yo o escalo a especialista?

## Puedes resolverlo con el programa + SII cuando

- es una venta/compra normal del giro;
- la documentación está completa;
- no hay operaciones internacionales;
- no hay reorganización societaria;
- no hay trabajadores dependientes;
- el F29 concilia con RCV y banco;
- la operación ya está cubierta por un caso y una regla versionada.

## Escala para revisión puntual cuando

- no sabes si un gasto es necesario/aceptado;
- existe IVA de uso común, proporcionalidad o exención;
- compras activo fijo relevante;
- pagas al extranjero;
- contratas trabajadores;
- haces préstamo accionista ↔ sociedad;
- aumentas/disminuyes capital;
- distribuyes dividendos o haces retiros relevantes;
- recibes citación, liquidación, giro o fiscalización;
- el SII difiere del cálculo y no puedes explicar la diferencia;
- una declaración jurada no está cubierta por el caso guía.

El objetivo no es depender permanentemente de un contador: es **saber cuándo una operación dejó de ser rutinaria**.
