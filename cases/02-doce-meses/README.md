# Caso 02 — Doce meses de operación

Construye una carpeta por período y simula 12 cierres. Introduce progresivamente:

- remanentes de IVA;
- notas de crédito;
- dos proveedores recurrentes;
- honorarios;
- meses sin movimiento;
- compra de un activo;
- retiro/distribución;
- patente;
- cierre anual y preparación de Operación Renta.

**Objetivo final:** poder explicar cada saldo anual remontándolo a transacciones y evidencia mensual.
